## Open source

### [portzilla](https://github.com/011010/portzilla) — Rust · MIT · [crates.io](https://crates.io/crates/portzilla) · [npm](https://www.npmjs.com/package/portzilla)

Coordination layer for parallel AI coding-agent sessions. Leases ports with owner
PIDs, intercepts `kill` so one agent can't murder another's dev server, and gives
each session its own slot with isolated ports, cache dirs and database.

Daemon-less single binary, exposed over MCP so an agent calls it as a tool instead
of scraping text. Full CI matrix, published to crates.io and npm.

### [AnyPS5](https://github.com/boykopovar/AnyPS5) — C++ · 61k stars

Toolchain that ports PS5 executables to Linux and Windows. 49 commits upstream,
plus a separate macOS track.
